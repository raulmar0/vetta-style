# Fotos de referencia

Suelta aquí tus fotos de rodadas, entrenamientos o eventos en formato `.jpg` o `.png`.

**Tips para que el póster quede increíble:**
- **Verticales (3:4 o 9:16)** funcionan mejor tanto para post como para story.
- Deja algo de **espacio libre arriba** (cielo, árboles o montaña sin personas) para que el titular no tape cascos ni caras.
- Si la foto tiene buena resolución (≥1080 px de ancho), los PNGs `2x` saldrán súper nítidos.
